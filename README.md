# WebH

Website danh bạ và blog về các địa điểm xỏ khuyên tại Đà Nẵng.

## Chức năng

- Danh sách 26 địa điểm theo 9 phường
- Bộ lọc theo khu vực, đánh giá và giờ mở cửa
- Google Maps nhúng trên trang chủ
- Thẻ chi tiết cho từng tiệm và liên kết Google Maps
- Các trang xu hướng, kiến thức, chăm sóc và bài viết chi tiết
- Giao diện responsive cho desktop và mobile

## Chạy cục bộ

Website sử dụng HTML, CSS và JavaScript thuần. Có thể chạy bằng một HTTP server tĩnh:

```bash
python -m http.server 4173
```

Sau đó mở `http://127.0.0.1:4173/index.html`.
